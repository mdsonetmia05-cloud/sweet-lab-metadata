Turn any image into a detailed prompt for AI image generators.

A Gemini API key is required. This web version sends your image to Google Gemini (cloud) using your own key. Your key is stored only in this browser's localStorage — it is never sent to any Sweet Lab server (there is none). This web version does not use the offline vision model from the Chrome extension; that model runs only inside the extension.
