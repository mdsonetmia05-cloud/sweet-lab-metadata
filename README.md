# Sweet Lab Metadata

AI Metadata Generator for stock content — dashboard edition.

Generate professional titles, keywords and descriptions for stock photos, vectors and videos using your own Gemini API key. Optimized for Adobe Stock buyers: titles 60–120 characters with no commas, keywords 40–49 in tiers with the first 10 carrying the most weight, plus 28 buyer-search phrases.

## Live

https://mdsonetmia05-cloud.github.io/sweet-lab-metadata/

## How to use

1. Open the link above.
2. Add your own Gemini API key (from [Google AI Studio](https://aistudio.google.com/api-keys)) — it is stored only in your browser, never sent to any server.
3. Upload images or vectors, click **Generate Metadata**, and download results as CSV, TXT or Sheet.
4. Use **Settings → Appearance** to switch between the cream-white and dark-navy themes, and **Language** to switch between English and Bangla.

## Notes

- No API key is bundled with this site. Without your own key, generation does not run.
- Supports JPG, PNG, WEBP, GIF, SVG, EPS, AI, MP4, WEBM, MOV. No file-size limit is claimed.
