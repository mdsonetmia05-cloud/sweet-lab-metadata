Frequently asked questions

Where do I get a Gemini API key?

Free from Google AI Studio — follow the “Get a free key” link above. No payment is needed for a key; Google’s free-tier limits apply.

Is my API key safe here?

Your key is saved only in this browser after it passes a real test with Google, and it is sent only to Google’s Gemini API when you generate. It is never sent to, or stored on, any Sweet Lab or SONET server.

Does PromptEx cost anything?

The tool itself is free. You use your own Gemini key, so Google’s free-tier limits apply — heavy use may need a paid Google plan, which is between you and Google.

Is an API key really required?

Yes. Generation does not run without a tested, saved key, and PromptEx never shows faked metadata in its place.

Which image formats are accepted?

JPG, PNG, WEBP, SVG, and EPS. SVG files are rendered to PNG in your browser before being sent to Gemini. EPS files are listed but cannot be previewed or read by Gemini vision — upload a JPG/PNG preview of the same artwork to generate its metadata.

What do Category and Releases mean in the CSV?

Category is the stock category you pick for each image (Adobe Stock’s 21 categories). Releases records whether a model or property release exists for the image; it defaults to “None” because PromptEx cannot know that — only you can. Both are your own entries, not AI guesses.
